# Internship ML Deployment Project

# house_price_prediction
Predicts the house price based on the size given as input
This project is a simple machine learning web app built using Streamlit.

## 🔗 Live App:
[Click here to view the deployed app](https://house-price-predict-app.streamlit.app/)

## 📁 Files:
- `app.py` : Main Streamlit code
- `requirements.txt` : Python dependencies




## ⚙️ How to run locally:
```bash
pip install -r requirements.txt
streamlit run app.py
